# משימות · משרד החקירות

אפליקציה למשימות, סידור עבודה ודיווחי משמרת.

| מה | איפה |
|---|---|
| האפליקציה עצמה (מה שהטלפונים טוענים) | הקבצים בתיקייה הראשית (`index.html`, `app.js` ועוד) · מתפרסמת אוטומטית ב-GitHub Pages |
| אפליקציית האנדרואיד (מעטפת שמתקינים) | `android/` · נבנית אוטומטית בכל שינוי ומתפרסמת ב-Releases |
| חוקי האבטחה של השרת | `firestore.rules` · מדביקים ב-Firebase > Firestore > Rules |
| הגדרות חיבור | `config.js` |

**עדכונים:** שינוי בקבצי האפליקציה מגיע לכל הטלפונים בפתיחה הבאה של האפליקציה, בלי להתקין מחדש.
שינוי בתיקייה `android/` בונה קובץ התקנה חדש.

**קישור הורדה לאנדרואיד:** `https://github.com/adambarhum15-blip/inv-office/releases/latest/download/inv-office.apk`

הנתונים (צוות, משימות, סידור, דיווחים) נשמרים ב-Firebase ולא בקוד. בקוד אין שמות, סיסמאות או נתונים אישיים.
